# Comprehensive Analysis of Rift Bloom Flower Sales Data
### Fictional Data Analytics & Business Intelligence Portfolio Project

## Overview

This project demonstrates an end-to-end data analytics workflow by transforming raw business data into meaningful insights and interactive dashboards.

Using a fictional flower export company, Rift Bloom, this project explores sales performance, customer trends, product analysis, and business opportunities through data cleaning, exploratory data analysis (EDA), SQL analysis, and Power BI visualization.

The objective is to demonstrate how data can support evidence-based decision-making and improve business performance.

---

# Project Objectives

- Load and explore business data using Python
- Perform data cleaning and preparation
- Conduct exploratory data analysis (EDA)
- Store and analyze data using SQL
- Develop business-focused KPIs
- Build interactive Power BI dashboards
- Generate analytical reports and presentations
- Communicate insights through data storytelling

---

# Dataset

The dataset represents fictional flower export business transactions, including:

- Customer information
- Product categories
- Sales transactions
- Export markets
- Order dates
- Revenue data
- Product performance
- Customer purchasing patterns

**Note:**  
The dataset is fictional and created for portfolio demonstration purposes. It does not represent a real company or confidential business information.
